## Basic usages

- When you alt-click a stopwatch icon on the left of Transform property like **Position**, then it shows **Expression** for it to change an animation using an expression.


## Move

Written in 2026/06/27

We can use a layer's move by a function like `wiggle(1, 5)`. This means the value changes about 1 time per second, with up to 5 pixels of variation from the original position.

For example, next animation is with `wiggle(4, 20)` in Position property.
